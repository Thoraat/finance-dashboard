# 💰 Finance Dashboard UI

## 📌 Overview

A clean and interactive **Finance Dashboard** built using React and Tailwind CSS.
This project allows users to track financial activity, analyze spending patterns, and gain meaningful insights from their data.

The goal of this project was to focus on **UI design, component structure, and state management**, rather than backend complexity.

## 🛠️ Tech Stack

* **Frontend:** React (Vite)
* **Styling:** Tailwind CSS
* **Charts:** Recharts
* **State Management:** React Hooks (useState)

## ✨ Features

### 📊 Dashboard Overview

* Summary cards for:

  * Total Income
  * Total Expenses
  * Balance
* Interactive charts:

  * Line chart (trend over time)
  * Pie chart (category-wise spending)

---

### 📋 Transactions Section

* Display of transaction list with:

  * Date
  * Amount
  * Category
  * Type (Income / Expense)
* Features:

  * Filtering (All / Income / Expense)
  * Clean tabular UI

---

### 🔐 Role-Based UI

* **Viewer:**

  * Can only view data
* **Admin:**

  * Can add new transactions
* Role switching via dropdown

---

### ➕ Add Transaction (Admin Feature)

* Modal popup form
* Fields:

  * Date
  * Amount
  * Category
  * Type
* Dynamically updates dashboard after adding

---

### 💡 Insights Section

* Highlights highest spending category
* Calculates monthly savings
* Provides smart feedback based on spending behavior

---

### 🎨 UI/UX Highlights

* Clean and modern dark theme
* Responsive layout
* Interactive hover effects
* Centered dashboard layout for better readability

---

## 🧠 Approach

* Broke UI into reusable components:

  * Navbar
  * SummaryCards
  * Charts
  * TransactionsTable
  * Insights
* Managed application state using React hooks
* Used mock data to simulate real-world financial tracking
* Focused on:

  * Simplicity
  * Readability
  * User experience
